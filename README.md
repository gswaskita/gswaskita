## 🌟 Tentang ADAScholar

**ADAScholar v1.0** adalah platform profil akademis mutakhir (*academic portfolio & researcher profiling engine*) yang dirancang khusus untuk memenuhi standar universitas top dunia dan kualifikasi supervisi doktoral internasional (UK, US, Australia, & Eropa).

Seringkali profil akademisi hanya mengandalkan Google Scholar statis, PDDIKTI, atau dokumen PDF CV yang kaku. **ADAScholar** hadir menjawab kebutuhan personal branding dosen dan peneliti:
1. Menampilkan **arah riset, metodologi, dan target proposal doktoral (PhD Target)** secara terstruktur dan meyakinkan.
2. Memvisualisasikan **tren sitasi tahunan, metrik Google Scholar, dan SINTA Garuda** secara interaktif.
3. Menyajikan katalog publikasi jurnal, buku ber-ISBN, catatan riset (*fieldwork notes*), serta galeri pengabdian masyarakat dalam satu ekosistem terpadu.
4. Dilengkapi **dashboard manajemen konten mandiri (CMS)** tanpa memerlukan keahlian pemrograman untuk memperbarui data.

## 🚀 Fitur-Fitur Unggulan

### 1. 🏛️ Executive Academic Hero & PhD Supervisory Banner
- **Identitas Akademisi Lengkap**: Nama lengkap, gelar (*prefix & suffix*), jabatan fungsional, institusi, serta tag pilar keilmuan adaptif yang rapi di perangkat mobile tanpa terpotong.
- **5 Badge Profil Akademik Resmi**: Terintegrasi langsung dengan logo resmi Google Scholar, ORCID, SINTA Kemdikbud, Scopus, dan ResearchGate.
- **Proposal Doktoral & CV Siap Unduh**: Tombol *"Download Academic CV"* otomatis mengunduh berkas PDF terbaru dan tombol *"Scholarly Inquiry & Supervision"* membuka komunikasi email terenkripsi.

### 2. 📈 Interactive Bibliometrics & Citation Trajectory
- **Live Google Scholar Metrics**: Total sitasi, *h-index*, dan *i10-index* dengan badge verifikasi.
- **Grafik Tren Sitasi Interaktif**: Mode tampilan grafik batang (*Graphic*), tabel angka tahunan (*Table*), maupun kombinasi (*Combination*) dengan kalkulasi pertumbuhan YoY (*Year-over-Year Peak Growth*).
- **SINTA Garuda & VOSviewer Mapping**: Integrasi visual grafik garis publikasi SINTA serta *embed* peta jejaring bibliometrik interaktif VOSviewer untuk visualisasi klaster riset.

### 3. 💬 Scholarly Discussion & Peer-Review Engine
- **Diskusi Akademis Interaktif**: Rekan peneliti dan mahasiswa dapat meninggalkan ulasan telaah kritis (*peer-review/comment*) pada artikel blog.
- **Sistem Moderasi Terintegrasi**: Dashboard CMS memungkinkan pemilik web memilih status komentar (*Approved*, *Pending*, atau *Hidden*).
- **Official Author Reply**: Fitur tanggapan resmi dari penulis dengan tanda verifikasi akademis.
- **Penyimpanan Permanen Git-Backed**: Seluruh komentar tersimpan abadi ke repositori GitHub via API tanpa risiko hilang saat restart server.

### 4. 🎛️ ADAScholar CMS Dashboard (Keystatic Git-Backed)
- Pengelolaan 100% mandiri tanpa database SQL yang lambat atau mahal. Semua data disimpan sebagai JSON/Markdoc terstruktur di Git.
- Menu rapi:
  1. **Profil & Dokumen PhD**: Biodata, kontak, riwayat pendidikan, target riset doktoral.
  2. **Teks Halaman & Refleksi**: Pengaturan judul, subjudul, dan kutipan filosofis somatik.
  3. **Publikasi & Sitasi**: Pengaturan artikel unggulan, sitasi Google Scholar, dan SINTA.
  4. **Tulisan, Pilar & Galeri**: Artikel blog, buku ber-ISBN, dokumentasi foto, dan feed Instagram.
  5. **Komunitas**: Moderasi dan jawaban diskusi ilmiah.

### 5. ⚡ Performa Tinggi, SEO & Dark Mode
- Dibangun di atas arsitektur **Astro 5 + React 19** untuk waktu muat instan (*near-zero JavaScript overhead*).
- **Dark / Light Mode**: Transisi mulus yang nyaman di mata untuk membaca naskah panjang.
- **SEO & Schema.org**: Dilengkapi metadata profil akademis Google, OpenGraph kartu sosial media, dan sitemap otomatis.

## 💻 Panduan Instalasi Lokal (Quickstart)

### Prasyarat
- **Node.js** (versi 18.x atau lebih baru disarankan)
- **npm** atau **pnpm**

### Langkah Menjalankan
```bash
# 1. Kloning repositori
git clone https://github.com/gswaskita/gswaskita.git
cd gswaskita

# 2. Pasang dependensi
npm install

# 3. Salin contoh berkas konfigurasi lingkungan
cp .env.example .env

# 4. Jalankan server pengembangan lokal
npm run dev
```

Buka peramban (*browser*) Anda:
- **Halaman Website Utama**: `http://localhost:3000`
- **Dashboard CMS ADAScholar**: `http://localhost:3000/keystatic`

## ☁️ Panduan Deploy ke Vercel & GitHub

Untuk mengaktifkan sinkronisasi otomatis antara Vercel dan GitHub saat website live di internet, siapkan variabel lingkungan (*Environment Variables*) di dashboard hosting Anda:

| Variabel Lingkungan | Deskripsi |
| :--- | :--- |
| `PUBLIC_KEYSTATIC_GITHUB_REPO` | Nama repositori GitHub publik/privat Anda (contoh: `gswaskita/gswaskita`). |
| `GITHUB_TOKEN` | GitHub Personal Access Token (izin cakupan `repo`) untuk penyimpanan otomatis komentar dan konten. |
